Setup & Usage Guide

Adding positions

Use + Add tab. Fill ticker, entry price, date. TP and SL are optional but unlock the progress bar and R/R ratio. After adding, download portfolio.json and commit it to your GitHub repo, then run the workflow.


TP Progress bar

Shows how far price has moved from your entry toward your TP target. When 90%+ reached, the row glows gold ⚡ as an alert.


R/R Ratio

Auto-calculated from Entry, TP, and SL. R/R = (TP − Entry) / (Entry − SL). A ratio above 2.0 is generally considered good.


Price updates

GitHub Actions runs Mon–Fri 22:00 UTC automatically. Manual trigger: GitHub → Actions → Update Stock Prices → Run workflow.

How to create a PAT

3. Personal access tokens → Tokens (classic)
4. Generate new token (classic)
5. Give it a name e.g. portfolio-tracker
6. Check the repo scope checkbox
7. Click Generate token → copy it here
