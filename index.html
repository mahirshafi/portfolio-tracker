How adding works
1. Fill in the form and click Add Position.
2. The position is saved to portfolio.json in your browser.
3. Download portfolio.json (button below) and commit it to your GitHub repo.
4. GitHub Actions will fetch the price automatically on next run.
5. You can also trigger the workflow manually in GitHub → Actions → Update Stock Prices → Run workflow.

Setup Guide

Step 1 — Create a GitHub repo

Create a new public repo (e.g. portfolio-tracker) and push all 4 files from the zip you downloaded.


Step 2 — Enable GitHub Pages

Go to repo Settings → Pages → Source: Deploy from branch → main → / (root). Save. Your dashboard will be live at https://username.github.io/portfolio-tracker/


Step 3 — Set your repo path

Open the dashboard, enter your username/repo in the setup banner and click Save.


Step 4 — Add positions

Use the Add Position tab. After adding, download portfolio.json and commit it to your repo.


Step 5 — Prices update automatically

GitHub Actions runs Mon–Fri at 22:00 UTC (after US market close). You can also trigger it manually: GitHub → Actions → Update Stock Prices → Run workflow.
